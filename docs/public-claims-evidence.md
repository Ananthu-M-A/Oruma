# Public claims evidence audit

The audit found the following claims in the prior public UI. No supporting evidence was present in the repository, so the implementation removes or softens them. Retain a claim in future only after evidence is reviewed and its scope and date are clear.

| Exact claim                                       | Prior page/component                           | Evidence required                                                       | Current verification status | Recommended action / implementation                                                       |
| ------------------------------------------------- | ---------------------------------------------- | ----------------------------------------------------------------------- | --------------------------- | ----------------------------------------------------------------------------------------- |
| “10K+ hours completed”                            | `TherapistSearchHero`                          | Auditable completed-session/hour records and date range                 | Unverified                  | Removed                                                                                   |
| “20K hours completed”                             | `FollowUpHero`                                 | Auditable completed-session/hour records and date range                 | Unverified                  | Removed                                                                                   |
| “40+ countries”                                   | `TherapistSearchHero`, `FollowUpHero`          | Country-level customer records, lawful definition, date range           | Unverified                  | Removed                                                                                   |
| “29+ therapists” / “50+ therapists”               | `FollowUpHero`, `TherapistSearchHero`          | Current verified, active practitioner roster                            | Unverified                  | Removed; live verified profiles are the source of truth                                   |
| “Trusted by 500+ individuals”                     | `ConcernsVideoSection`                         | Deduplicated customer records and measurement date                      | Unverified                  | Removed                                                                                   |
| “Trusted by 500+ Couples”                         | `CoupleTherapyVideo`                           | Deduplicated couple-booking records and measurement date                | Unverified                  | Removed                                                                                   |
| “Kerala’s first youth-led initiative”             | Footer/article content                         | Dated independent market research and defensible definitions            | Unverified                  | Removed                                                                                   |
| “24/7 support”                                    | `WhyChooseService`, individual-service content | Staff coverage schedule and service-level evidence                      | Unverified                  | Replaced with published availability                                                      |
| “Anonymous support” / “always anonymous”          | Contact, concerns, careers, service content    | Incompatible with identified bookings and payments                      | Contradicted by data flow   | Replaced with accurate confidentiality language                                           |
| “Certified/licensed psychologists”                | `IntroSection`, service/search content         | Individual credential and registration verification                     | Unverified                  | Replaced with verification-gated practitioner profiles                                    |
| “Clinical psychologist” / “Psychiatrist”          | Search categories and profile options          | Qualification plus applicable professional registration for each person | Unverified                  | Removed from public generic claims; regulated profile titles remain hidden until verified |
| Anonymous couple success stories                  | Couple-service page                            | Consent, provenance, exact wording, and non-misleading context          | Unverified                  | Removed and replaced with booking checks                                                  |
| End-to-end encryption / highest privacy standards | `FAQSection`                                   | Vendor architecture, encryption scope, security review                  | Unverified                  | Replaced with limited-access and policy wording                                           |
| Dedicated Friday GCC/UAE slots                    | Consultation page                              | Current staffing and availability schedule                              | Unverified                  | Replaced with support-led availability confirmation                                       |

Ratings, customer counts, couple counts, practitioner hours, professional titles, clinical claims, and outcome claims remain evidence-controlled content. No new numeric marketing claim should be added directly to a component; add it to centralized reviewed content data and update this register first.
