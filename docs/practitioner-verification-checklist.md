# Practitioner verification checklist

No repository document provides evidence for a particular practitioner’s regulated title, qualification, registration, or experience. Existing practitioner records are therefore migrated to `UNVERIFIED` and hidden until an administrator completes this checklist. `[VERIFICATION REQUIRED]` is an internal marker and must never appear on a public profile.

For every practitioner, retain an access-controlled evidence record outside the public source repository and check:

| Information                                | Evidence/check                                                                       | Current repository status |
| ------------------------------------------ | ------------------------------------------------------------------------------------ | ------------------------- |
| Full legal/display name                    | Government or professional identity evidence, handled privately                      | [VERIFICATION REQUIRED]   |
| Exact professional role                    | Role supported by qualifications and applicable law                                  | [VERIFICATION REQUIRED]   |
| Qualification                              | Original or issuer-verifiable certificate                                            | [VERIFICATION REQUIRED]   |
| Awarding institution                       | Institution and course independently checked                                         | [VERIFICATION REQUIRED]   |
| Years of experience                        | CV plus employer/engagement evidence                                                 | [VERIFICATION REQUIRED]   |
| Experience hours, if claimed               | Auditable source and calculation                                                     | [VERIFICATION REQUIRED]   |
| Registration number, if legally applicable | Verify directly with registration authority                                          | [VERIFICATION REQUIRED]   |
| Registration authority                     | Correct authority for the claimed role                                               | [VERIFICATION REQUIRED]   |
| Areas of practice                          | Consistent with verified training and scope                                          | [VERIFICATION REQUIRED]   |
| Consultation type                          | Online modes the practitioner actually offers                                        | [VERIFICATION REQUIRED]   |
| Session duration                           | Written practitioner/Oruma agreement                                                 | [VERIFICATION REQUIRED]   |
| Consultation price                         | Approved current commercial schedule                                                 | [VERIFICATION REQUIRED]   |
| Engagement relationship                    | Employee, contractor, or independent professional, accurately stated                 | [VERIFICATION REQUIRED]   |
| Practitioner agreement                     | Signed, current agreement covering scope, privacy, delivery, refunds, and complaints | [VERIFICATION REQUIRED]   |

Only an administrator may set `verificationStatus` to `VERIFIED`. A profile must also contain all publication-required fields before it can be activated. Registration fields may be empty only when registration is not legally applicable to the accurately described role; record that decision in the private review file.
